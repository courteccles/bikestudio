# S-REF — Reference Test Set

**Status:** approved 2026-11-01. **Source:** D14 in `../decisions.md`.

## Purpose

Provide known answers that prove bikestudio's geometry and linkage results are accurate. This is version 1 success criterion 1.

## Decisions

| # | Decision | Status |
|---|---|---|
| R1 | Geometry tests use 3–5 real bikes from published geometry charts (rigid, hardtail, full suspension). Linkage tests use 6 synthetic frames: rigid, hardtail, single pivot, Horst link, split pivot, mid-drive e-bike. | Confirmed (revised) |
| R2 | Known linkage answers come from the reference calculator: a separate program, outside bikestudio's code, using textbook geometry and a stated center of mass. No third-party tool. | Confirmed; risk accepted: a shared formula error would pass silently |
| R3 | Linkage test frames are synthetic: exact, chosen pivot coordinates, not measured from real bikes. | Confirmed |
| R4 | The value of bikestudio's curves is internal consistency: every design is computed the same way, so designs compare fairly with each other. Matching manufacturer curves isn't a goal, because manufacturers aren't consistent with each other. If later comparison shows bikestudio differs significantly from published curves, the tests are revisited then. | Confirmed |
| R5 | Center of mass for force answers: (a) known-answer tests use one fixed, stated center-of-mass point on every synthetic frame, independent of the rider model; (b) snapshot tests use the default Medium rider's center of mass to flag any pipeline change. | Confirmed |
| R6 | Geometry tests are a looser gate: every chart value bikestudio solves must fall within a tolerance of the published value, or the test fails. Tolerance: ±3 mm for lengths and ±0.3° for angles, on every chart value. | Confirmed |
| R7 | When a published chart contradicts itself beyond tolerance, correct that value in the test data and record the original value, the correction and the reason next to it. | Confirmed |
| R8 | The reference calculator is Python with NumPy, in `reference-calculator/` in this repository. It shares no code with bikestudio, solves each four-bar directly, and writes known answers as JSON that the Rust tests read. | Confirmed |

## Deliverables

1. `reference-calculator/`: the Python reference calculator, with a README stating every formula, its source, and the fixed center-of-mass point (R5a).
2. Six synthetic linkage frames as data files, with exact pivot coordinates (R1, R3).
3. Known answers for each synthetic frame as JSON, generated by the reference calculator (R8).
4. 3–5 published geometry charts as data files, each with its source and any corrections (R1, R7).

## Done when

- The reference calculator produces known answers for all six synthetic frames.
- Every geometry chart is recorded with its source, and every correction is documented.
- The Rust tests in S-GEOM, S-KINEMATICS and S-FORCES can load the fixtures. (They fail until those specs are built.)

## Architecture choices confirmed during this spec

- A `bike-export` crate owns all exports and reads only `Project` and `Solved`.
- Naive tubes live in `bike-geometry`.
- Export libraries: `dxf`, `svg`, `csv`, and `printpdf` or `krilla` for PDF (to be evaluated).
